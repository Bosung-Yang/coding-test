# 2번. 로그 압축

## 문제
장비 상태 로그는 알파벳 대문자 한 글자로 기록되며, 같은 상태가 오래 이어지는 경우가 많습니다. 저장 공간을 줄이기 위해 다음 규칙으로 로그를 압축합니다.

- 같은 문자가 **연속으로 2번 이상** 나오면 `문자 + 반복 횟수`로 바꿉니다. (예: `AAA` → `A3`)
- 연속으로 **1번만** 나오면 횟수 없이 문자만 씁니다. (예: `B` → `B`)
- 반복 횟수는 10 이상일 수 있으며, 그대로 숫자로 씁니다. (예: 문자 Z가 12번 → `Z12`)

로그 문자열 `s`가 주어질 때, 압축한 문자열을 return 하도록 `solution` 함수를 완성하세요.

## 제한사항
- 1 ≤ `s`의 길이 ≤ 1,000
- `s`는 알파벳 대문자로만 이루어져 있습니다.

## 함수 시그니처
```cpp
string solution(string s)
```

## 입출력 예
| s | result |
|---|---|
| `"AAABCC"` | `"A3BC2"` |
| `"ABCD"` | `"ABCD"` |
| `"ZZZZZZZZZZZZ"` | `"Z12"` |

## 입출력 예 설명
**예 #1**: `AAA` → `A3`, `B` → `B`, `CC` → `C2` 이므로 `A3BC2`입니다.

**예 #2**: 연속된 문자가 없으므로 그대로입니다.

**예 #3**: Z가 12번 연속이므로 `Z12`입니다.

## 참고
`to_string(정수)`는 `<string>` 헤더에 포함되어 있어 사용할 수 있습니다.
