# 3번. 경유 배송

## 문제
무인 운반차(AGV)가 R × C 격자 모양의 공장에서 부품을 배송합니다. 각 칸은 다음 중 하나입니다.

| 문자 | 의미 |
|---|---|
| `S` | 출발 위치 (정확히 1개) |
| `P` | 부품 창고 (정확히 1개) |
| `E` | 도착 위치 (정확히 1개) |
| `.` | 빈 칸 |
| `#` | 벽 (지나갈 수 없음) |

운반차는 한 번에 상하좌우로 한 칸씩 이동합니다. 운반차는 `S`에서 출발해 **먼저 `P`에 들러 부품을 실은 뒤**, `E`에 도착해야 합니다. 이동 중에 `S`, `P`, `E` 칸을 지나가는 것은 자유롭습니다. 단, 부품을 싣기 전에 `E`를 지나가는 것은 도착으로 치지 않습니다.

`S`에서 출발해 `P`를 거쳐 `E`에 도착하는 **최소 이동 횟수**를 return 하도록 `solution` 함수를 완성하세요. 불가능하다면 `-1`을 return 하세요.

## 제한사항
- 1 ≤ R, C ≤ 100
- `grid`의 각 문자열 길이는 C이고, 위 다섯 문자로만 이루어져 있습니다.

## 함수 시그니처
```cpp
int solution(vector<string> grid)
```

## 입출력 예
| grid | result |
|---|---|
| `["S.#E", "..#.", "P..."]` | `7` |
| `["SPE"]` | `2` |
| `["S#E", "##.", "P.."]` | `-1` |
| `["SEP"]` | `3` |

## 입출력 예 설명
**예 #1**: S → P 아래로 2번, P → E 오른쪽 3번 + 위로 2번. 총 7번입니다.

**예 #2**: S → P 1번, P → E 1번. 총 2번입니다.

**예 #3**: S가 벽에 둘러싸여 P에 갈 수 없습니다.

**예 #4**: S → P로 가는 길에 E를 지나지만, 부품을 싣기 전이라 도착이 아닙니다. S → P 2번, P → E 1번. 총 3번입니다.
