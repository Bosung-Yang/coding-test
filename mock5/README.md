# 모의고사 5회 (실전 난이도)

**시험 시간 120분 · 4문제 · C++ · `solution` 함수 작성**

## 규칙
- **문제 틀에 미리 선언된 헤더(`<string>`, `<vector>`)만 사용하세요.** 다른 헤더를 쓰면 `./run.sh`가 ⚠️ 경고를 띄워요.
- 주석과 코딩 스타일도 채점된다는 후기가 있어요.
- 숨은 테스트 케이스가 있어요.
- **목표: 120분 안에 4문제 전부 통과. 다 풀고 남은 시간에는 반드시 예제를 실행해서 확인하기.**

## 문제
| 번호 | 문제 | 유형 | 권장 시간 |
|---|---|---|---|
| 1 | [생산량 집계](p1.md) | 2차원 배열 | 15분 |
| 2 | [로그 압축](p2.md) | 문자열 | 20분 |
| 3 | [경유 배송](p3.md) | BFS 최단 거리 | 35분 |
| 4 | [검사원 배치](p4.md) | 백트래킹 | 40분 |

## 시간 기록
문제를 시작할 때 "p1 시작"처럼 말해주시면 기록해 드려요.

## 채점 / 디버깅
```bash
./run.sh mock5/p1          # 전체 테스트 채점
./debug.sh mock5/p1 3      # 3번 테스트 하나만 실행 (cout 출력 전부 보임, 범위 밖 접근 감지)
```
