# 4번. 검사원 배치

## 문제
N × N 격자 모양의 클린룸에 검사원 k명을 배치하려고 합니다. 각 칸에는 그 칸의 **검사 효율** `grid[i][j]`가 적혀 있고, 효율이 0인 칸에는 장비가 있어 검사원을 배치할 수 없습니다.

검사원끼리 서로 방해가 되지 않도록, 두 검사원을 **상하좌우로 인접한 칸**에 배치할 수 없습니다. (대각선으로 인접한 것은 괜찮습니다.) 한 칸에는 검사원을 한 명만 배치할 수 있습니다.

검사원 **정확히 k명**을 배치했을 때, 배치한 칸의 검사 효율 합의 **최댓값**을 return 하도록 `solution` 함수를 완성하세요. k명을 배치할 수 없다면 `-1`을 return 하세요.

## 제한사항
- 1 ≤ N ≤ 5
- 0 ≤ `grid[i][j]` ≤ 9
- 1 ≤ k ≤ 6

## 함수 시그니처
```cpp
int solution(vector<vector<int>> grid, int k)
```

## 입출력 예
| grid | k | result |
|---|---|---|
| `[[5,1,5],[1,9,1],[5,1,5]]` | 4 | `24` |
| `[[5,1,5],[1,9,1],[5,1,5]]` | 5 | `29` |
| `[[5,1,5],[1,9,1],[5,1,5]]` | 6 | `-1` |
| `[[0,7],[7,0]]` | 2 | `14` |

## 입출력 예 설명
```
5 1 5
1 9 1
5 1 5
```
**예 #1**: 가운데 9와 모서리 5 세 개를 고르면 24입니다. 가운데와 모서리는 대각선이라 괜찮습니다. 모서리 네 개만 고르면 20이라 더 작습니다.

**예 #2**: 가운데 9와 모서리 5 네 개를 고르면 29입니다.

**예 #3**: 3 × 3 격자에서 서로 인접하지 않게 고를 수 있는 칸은 최대 5개입니다.

**예 #4**: 효율 7인 두 칸은 대각선이라 함께 배치할 수 있습니다.
