# 1번. 칩 등급 판정

## 문제
웨이퍼 위에 N × M개의 칩이 격자 모양으로 놓여 있고, 각 칩의 검사 점수 `score[i][j]`가 주어집니다.

먼저 점수로 각 칩의 **기본 등급**을 정합니다.

| 점수 | 기본 등급 |
|---|---|
| 90 이상 | A |
| 70 이상 90 미만 | B |
| 70 미만 | F |

그다음, 주변 8칸(상하좌우 + 대각선)에 기본 등급이 **F인 칩이 3개 이상** 있으면 그 칩의 등급을 **한 단계 내립니다.** (A → B, B → F, F는 그대로 F)

**강등 여부는 모두 기본 등급을 기준으로 동시에 판단합니다.** 강등되어 F가 된 칩은 다른 칩의 판정에 영향을 주지 않습니다.

최종 등급이 A, B, F인 칩의 개수를 차례대로 담은 배열을 return 하도록 `solution` 함수를 완성하세요.

## 제한사항
- 1 ≤ N, M ≤ 100
- 0 ≤ `score[i][j]` ≤ 100
- 격자 밖은 칩이 없는 것으로 봅니다.

## 함수 시그니처
```cpp
vector<int> solution(vector<vector<int>> score)
```

## 입출력 예
| score | result |
|---|---|
| `[[95,95,50],[95,80,60],[30,95,95]]` | `[5,0,4]` |
| `[[100,40],[40,40]]` | `[0,1,3]` |

## 입출력 예 설명
**예 #1**: 기본 등급은 다음과 같습니다.
```
A A F
A B F
F A A
```
가운데 B 칩의 주변 8칸에는 F가 3개 있으므로 F로 강등됩니다. 나머지 칩은 주변 F가 2개 이하입니다. 최종적으로 A 5개, B 0개, F 4개입니다.

**예 #2**: 왼쪽 위 A 칩은 주변 3칸이 모두 F이므로 B로 강등됩니다.
