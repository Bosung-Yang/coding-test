# 3번. 레이저 구역 통과

## 문제
점검 로봇이 R × C 격자 모양의 공장을 지나 목적지로 가야 합니다. 각 칸은 다음 중 하나입니다.

| 문자 | 의미 |
|---|---|
| `S` | 출발 위치 (정확히 1개) |
| `E` | 목적지 (정확히 1개) |
| `.` | 빈 칸 |
| `#` | 벽 (지나갈 수 없음) |
| `L` | 레이저 구역 |

로봇은 한 번에 상하좌우로 한 칸씩 이동합니다. 레이저 구역에 들어가면 보호막이 하나씩 소모되며, 로봇은 보호막을 **k개** 가지고 있습니다. 즉, 레이저 구역에는 **최대 k번**까지 들어갈 수 있습니다. 같은 레이저 칸에 다시 들어가도 보호막이 또 소모됩니다.

목적지까지 가는 **최소 이동 횟수**를 return 하도록 `solution` 함수를 완성하세요. 갈 수 없다면 `-1`을 return 하세요.

## 제한사항
- 1 ≤ R, C ≤ 100
- 0 ≤ k ≤ 10
- `grid`의 각 문자열 길이는 C이고, 위 다섯 문자로만 이루어져 있습니다.

## 함수 시그니처
```cpp
int solution(vector<string> grid, int k)
```

## 입출력 예
| grid | k | result |
|---|---|---|
| `["SLE", ".#.", "..."]` | 1 | `2` |
| `["SLE", ".#.", "..."]` | 0 | `6` |
| `["S.L.", "##L#", "...E"]` | 1 | `-1` |

## 입출력 예 설명
**예 #1**: 레이저 구역을 한 번 통과하여 오른쪽으로 두 칸 이동합니다.

**예 #2**: 보호막이 없으므로 아래 → 아래 → 오른쪽 → 오른쪽 → 위 → 위로 돌아갑니다.

**예 #3**: 목적지로 가려면 레이저 구역을 두 번 지나야 하는데, 보호막이 1개뿐입니다.
