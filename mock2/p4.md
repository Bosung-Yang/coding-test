# 4번. 작업 분배

## 문제
n개의 작업(0번 ~ n-1번)을 m대의 장비에 나눠 맡기려고 합니다. 작업 i를 처리하는 데는 `times[i]`분이 걸리며, 각 작업은 정확히 한 장비에 배정해야 합니다. 한 장비는 배정된 작업을 하나씩 차례로 처리하므로, 그 장비의 **처리 시간은 배정된 작업 시간의 합**입니다. 작업을 하나도 받지 않은 장비가 있어도 됩니다.

일부 작업들은 서로 간섭을 일으켜 **같은 장비에 배정할 수 없습니다.** `conflicts`의 각 원소 `[a, b]`는 작업 a와 작업 b를 같은 장비에 배정할 수 없다는 뜻입니다.

모든 작업이 끝나는 시간, 즉 **장비 처리 시간 중 최댓값을 최소로** 했을 때의 값을 return 하도록 `solution` 함수를 완성하세요. 조건을 만족하도록 배정할 수 없다면 `-1`을 return 하세요.

## 제한사항
- 1 ≤ n ≤ 12 (n = `times`의 길이)
- 1 ≤ m ≤ 4
- 1 ≤ `times[i]` ≤ 100
- 0 ≤ `conflicts`의 길이 ≤ 66
- `conflicts`의 각 원소 `[a, b]`는 0 ≤ a, b < n, a ≠ b이며, 같은 쌍이 중복되지 않습니다.

## 함수 시그니처
```cpp
int solution(vector<int> times, int m, vector<vector<int>> conflicts)
```

## 입출력 예
| times | m | conflicts | result |
|---|---|---|---|
| `[5,3,4,2]` | 2 | `[]` | `7` |
| `[5,3,4,2]` | 2 | `[[0,3]]` | `8` |
| `[1,1,1]` | 2 | `[[0,1],[1,2],[0,2]]` | `-1` |

## 입출력 예 설명
**예 #1**: {5, 2}와 {3, 4}로 나누면 두 장비 모두 7분입니다.

**예 #2**: 5분 작업과 2분 작업을 함께 둘 수 없습니다. {5, 3}과 {4, 2}로 나누면 최대 8분입니다.

**예 #3**: 세 작업이 모두 서로 간섭하므로 장비 2대로는 나눌 수 없습니다.
