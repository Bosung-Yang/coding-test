## 이번 세트 규칙 (후기 반영)
- **문제 틀에 미리 선언된 헤더(`<string>`, `<vector>`)만 사용하세요.** 다른 헤더를 추가하면 감점된다는 후기가 있어요.
  - `<algorithm>`(sort, min, max), `<queue>`, `<map>`, `<sstream>` 등을 쓰지 않아요.
  - 필요하면 직접 구현하세요. (예: `vector` + 앞 인덱스로 큐 만들기, 직접 min/max 함수 만들기)
  - 다른 헤더를 쓰면 `./run.sh`가 ⚠️ 경고를 띄워요.
- **주석과 코딩 스타일도 채점된다는 후기**가 있어요. 핵심 로직에 짧은 주석을 달고, 변수 이름을 의미 있게 지으세요.
- 숨은 테스트 케이스가 있어요. 예제만 맞는다고 끝이 아니에요.
