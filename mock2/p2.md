# 2번. 메모리 할당기

## 문제
크기가 n인 메모리가 있고, 각 칸의 주소는 0번부터 n-1번입니다. 처음에는 모든 칸이 비어 있습니다. 다음 두 종류의 명령을 차례대로 처리합니다.

| 명령 | 형식 | 동작 |
|---|---|---|
| 할당 | `"A id size"` | **연속된 빈 칸 size개**를 찾아 프로그램 `id`에게 줍니다. 가능한 위치가 여러 곳이면 **시작 주소가 가장 작은** 곳을 고릅니다. 결과로 시작 주소를 기록하고, 공간이 없으면 할당하지 않고 `-1`을 기록합니다. |
| 해제 | `"F id"` | 프로그램 `id`가 가진 칸을 모두 비웁니다. `id`가 현재 메모리를 가지고 있지 않으면 아무 일도 하지 않습니다. |

모든 명령을 처리한 뒤, **할당 명령의 결과**를 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성하세요.

## 제한사항
- 1 ≤ n ≤ 1,000
- 1 ≤ `commands`의 길이 ≤ 1,000
- 1 ≤ id ≤ 1,000, 1 ≤ size ≤ 1,000
- 할당 명령의 id는 모두 서로 다릅니다. (해제된 id가 다시 할당되는 일은 없습니다.)
- 할당 명령은 1개 이상 있습니다.
- 명령의 각 부분은 공백 하나로 구분됩니다.

## 함수 시그니처
```cpp
vector<int> solution(int n, vector<string> commands)
```

## 입출력 예
| n | commands | result |
|---|---|---|
| 10 | `["A 1 3", "A 2 4", "F 1", "A 3 2", "A 4 2", "A 5 5"]` | `[0, 3, 0, 7, -1]` |
| 5 | `["A 1 5", "A 2 1", "F 1", "A 3 6", "A 4 5"]` | `[0, -1, -1, 0]` |

## 입출력 예 설명
**예 #1** (`.`은 빈 칸)
```
A 1 3 → 111.......   결과 0
A 2 4 → 1112222...   결과 3
F 1   → ...2222...
A 3 2 → 33.2222...   결과 0
A 4 2 → 33.222244.   결과 7  (2번 칸은 1칸뿐이라 불가)
A 5 5 → 연속 5칸 없음  결과 -1
```

**예 #2** (해제 명령 `F`는 결과 배열에 아무것도 기록하지 않습니다)
```
A 1 5 → 11111   결과 0
A 2 1 → 11111   결과 -1  (빈 칸 없음)
F 1   → .....   (기록 없음)
A 3 6 → .....   결과 -1  (메모리 크기보다 큼)
A 4 5 → 44444   결과 0
```
할당 명령 4개의 결과만 모아 `[0, -1, -1, 0]`입니다.
