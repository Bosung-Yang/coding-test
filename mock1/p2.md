# 2번. 공정 순서 정하기

## 문제
n개의 공정(0번 ~ n-1번)을 한 장비에서 **한 번씩** 모두 수행해야 합니다. 공정 i 다음에 바로 공정 j를 수행하면 장비 설정을 바꾸는 **전환 비용** `cost[i][j]`가 듭니다. 첫 공정에는 비용이 들지 않습니다.

또한 일부 공정 사이에는 선후 관계가 있습니다. `order`의 각 원소 `[a, b]`는 **공정 a가 공정 b보다 먼저**(바로 직전일 필요는 없음) 수행되어야 한다는 뜻입니다.

모든 선후 관계를 만족하는 순서 중 **전환 비용 합의 최솟값**을 return 하도록 `solution` 함수를 완성하세요. 선후 관계를 모두 만족하는 순서가 없다면 `-1`을 return 하세요.

## 제한사항
- 1 ≤ n ≤ 10
- n은 따로 주어지지 않으며, **`cost`의 길이가 곧 n**입니다. (테스트마다 n이 다를 수 있음)
- `cost`는 n × n 배열이고, 0 ≤ `cost[i][j]` ≤ 1,000, `cost[i][i]` = 0
- 0 ≤ `order`의 길이 ≤ 45
- `order`의 각 원소 `[a, b]`는 0 ≤ a, b < n, a ≠ b이며, 같은 원소가 중복되지 않습니다.

## 함수 시그니처
```cpp
int solution(vector<vector<int>> cost, vector<vector<int>> order)
```

## 입출력 예
| cost | order | result |
|---|---|---|
| `[[0,5,1],[2,0,4],[3,6,0]]` | `[[2,1]]` | `7` |
| `[[0,7],[3,0]]` | `[[0,1],[1,0]]` | `-1` |
| `[[0,5,1],[2,0,4],[3,6,0]]` | `[]` | `3` |

## 입출력 예 설명
**예 #1**: 2번이 1번보다 먼저 와야 하므로 가능한 순서는 0→2→1 (1+6=7), 2→0→1 (3+5=8), 2→1→0 (6+2=8)입니다. 최솟값은 7입니다.

**예 #2**: 0이 1보다 먼저이면서 1이 0보다 먼저일 수는 없으므로 -1입니다.

**예 #3**: 제약이 없으면 1→0→2 (2+1=3)가 최소입니다.
