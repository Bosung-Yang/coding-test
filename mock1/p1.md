# 1번. 장비 가동 시간

## 문제
반도체 공장의 각 장비는 켜질 때 `ON`, 꺼질 때 `OFF` 로그를 남깁니다. 로그는 `"장비ID HH:MM 상태"` 형식의 문자열입니다.

로그가 **시간 순서와 상관없이 섞여서** 주어질 때, 장비별 총 가동 시간(분)을 구하고 다음 기준으로 정렬한 장비 ID 목록을 return 하도록 `solution` 함수를 완성하세요.

1. 총 가동 시간이 **긴** 순서
2. 가동 시간이 같으면 장비 ID의 **사전순**

가동 시간은 각 `ON`부터 바로 다음 `OFF`까지의 시간을 모두 더한 값입니다.

## 제한사항
- 1 ≤ `logs`의 길이 ≤ 1,000
- 장비 ID는 알파벳 대문자와 숫자로 이루어진 길이 1 이상 10 이하의 문자열입니다.
- 시각은 `00:00` ~ `23:59`이며, 모든 로그는 같은 날의 기록입니다.
- 한 장비의 로그를 시각순으로 정렬하면 `ON`, `OFF`가 번갈아 나타나고, `ON`으로 시작해서 `OFF`로 끝납니다.
- 한 장비 안에서 같은 시각의 로그는 없습니다.

## 함수 시그니처
```cpp
vector<string> solution(vector<string> logs)
```

## 입출력 예
| logs | result |
|---|---|
| `["EQ2 09:00 ON", "EQ1 08:30 ON", "EQ2 09:40 OFF", "EQ1 10:00 OFF", "EQ2 13:00 ON", "EQ2 13:50 OFF"]` | `["EQ1", "EQ2"]` |
| `["B 12:00 OFF", "A 00:00 ON", "B 11:30 ON", "A 00:10 OFF", "B 08:00 ON", "B 08:05 OFF"]` | `["B", "A"]` |

## 입출력 예 설명
**예 #1**: EQ1은 08:30~10:00으로 90분, EQ2는 40분 + 50분 = 90분입니다. 시간이 같으므로 사전순으로 EQ1, EQ2입니다.

**예 #2**: 로그가 섞여 있습니다. B를 시각순으로 정렬하면 08:00 ON, 08:05 OFF, 11:30 ON, 12:00 OFF이므로 5분 + 30분 = 35분입니다. A는 10분입니다.
