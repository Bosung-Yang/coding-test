# 3번. 가스 누출 대피

## 문제
클린룸에서 유독 가스가 누출되었습니다. 클린룸은 R × C 격자이며, 각 칸은 다음 중 하나입니다.

| 문자 | 의미 |
|---|---|
| `S` | 작업자의 시작 위치 (정확히 1개) |
| `E` | 비상구 (정확히 1개) |
| `G` | 가스 누출 지점 (0개 이상) |
| `#` | 벽 |
| `.` | 빈 칸 |

매 1분마다 다음이 순서대로 일어납니다.
1. **가스 확산**: 가스가 있는 칸과 상하좌우로 인접한 빈 칸(`.`, `S`)으로 가스가 퍼집니다. 가스는 벽과 비상구로는 퍼지지 않습니다.
2. **작업자 이동**: 작업자는 상하좌우로 한 칸 이동하거나 제자리에 머뭅니다. 벽, 누출 지점(`G`), **가스가 있는 칸**으로는 갈 수 없습니다. 작업자가 있던 칸에 가스가 퍼졌다면 그 칸에 머무를 수도 없습니다.

작업자가 비상구에 도착하는 **최소 시간(분)**을 return 하도록 `solution` 함수를 완성하세요. 비상구에 도착할 수 없다면 `-1`을 return 하세요.

## 제한사항
- 1 ≤ R, C ≤ 50
- `grid`의 각 문자열 길이는 C이고, 위 다섯 문자로만 이루어져 있습니다.
- 시작 시점(0분)에는 `G` 칸에만 가스가 있습니다.

## 함수 시그니처
```cpp
int solution(vector<string> grid)
```

## 입출력 예
| grid | result |
|---|---|
| `["S..", ".G.", "..E"]` | `-1` |
| `["S...", "....", "...E", "G..."]` | `5` |
| `["S.G", "...", "E.."]` | `2` |

## 입출력 예 설명
**예 #1**: 1분이 되면 가스가 (0,1), (1,0)으로 퍼집니다. 작업자는 그 칸으로 이동할 수 없고, 2분에는 시작 칸에도 가스가 퍼집니다.

**예 #2**: 오른쪽 위로 돌아가는 경로 (0,1)→(0,2)→(0,3)→(1,3)→E 로 이동하면, 각 칸에 가스보다 먼저 도착하여 5분 만에 탈출합니다.

**예 #3**: 아래로 두 칸 (1,0)→E 이동하면 2분입니다.
