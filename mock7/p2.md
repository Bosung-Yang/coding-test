# 2번. 괄호 검사

## 문제
장비 설정 파일의 괄호가 올바르게 짝지어져 있는지 검사하려고 합니다. 문자열 `s`는 세 종류의 괄호 `()`, `[]`, `{}`로만 이루어져 있습니다.

괄호가 **올바르다**는 것은 다음을 모두 만족하는 것입니다.
- 모든 여는 괄호에는 같은 종류의 닫는 괄호가 짝지어져 있습니다.
- 괄호 쌍은 서로 엇갈리지 않습니다. 예를 들어 `([])`는 올바르지만 `([)]`는 올바르지 않습니다.

왼쪽부터 한 글자씩 검사할 때,
- 문자열이 올바르면 `-1`을 return 합니다.
- **짝이 맞지 않는 닫는 괄호**를 만나면, 그 문자의 **인덱스**(0부터 시작)를 return 합니다. 닫는 괄호 앞에 짝지을 여는 괄호가 없는 경우도 포함됩니다.
- 끝까지 검사했는데 **닫히지 않은 여는 괄호**가 남아 있으면, 문자열의 **길이**를 return 합니다.

## 제한사항
- 1 ≤ `s`의 길이 ≤ 1,000
- `s`는 `(`, `)`, `[`, `]`, `{`, `}`로만 이루어져 있습니다.

## 함수 시그니처
```cpp
int solution(string s)
```

## 입출력 예
| s | result |
|---|---|
| `"([]{})"` | `-1` |
| `"([)]"` | `2` |
| `"(("` | `2` |
| `"])"` | `0` |
| `"{[()]}]"` | `6` |

## 입출력 예 설명
**예 #1**: 모든 괄호가 올바르게 짝지어져 있습니다.

**예 #2**: 인덱스 2의 `)`를 만났을 때 가장 최근에 열린 괄호는 `[`입니다. 종류가 다르므로 2입니다.

**예 #3**: 끝까지 검사했는데 `(` 두 개가 닫히지 않았습니다. 문자열 길이 2를 return 합니다.

**예 #4**: 인덱스 0의 `]` 앞에 여는 괄호가 없습니다.

**예 #5**: 앞의 `{[()]}`는 올바르지만, 인덱스 6의 `]` 앞에 남은 여는 괄호가 없습니다.
