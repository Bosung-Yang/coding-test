# 4번. 연산자 배치

## 문제
n개의 자연수 `nums`가 순서대로 주어지고, 그 사이에 넣을 연산자 n-1개가 주어집니다. `ops`는 길이 4의 배열로, 차례대로 덧셈(`+`), 뺄셈(`-`), 곱셈(`×`), 나눗셈(`÷`)의 **개수**입니다.

수의 순서는 바꿀 수 없고, 수와 수 사이에 연산자를 **하나씩** 넣어 식을 만듭니다. 주어진 연산자는 모두 정확히 한 번씩 사용해야 합니다.

식은 연산자 우선순위를 무시하고 **앞에서부터 차례대로** 계산합니다. 나눗셈은 정수 나눗셈으로, 몫의 소수점 아래를 버립니다. 결과가 음수일 때도 **0에 가까운 쪽으로** 버립니다. (C++의 `/` 연산과 같습니다. 예: `-7 ÷ 3 = -2`)

만들 수 있는 식의 결과 중 **최댓값과 최솟값**을 `[최댓값, 최솟값]` 형태로 return 하도록 `solution` 함수를 완성하세요.

## 제한사항
- 2 ≤ n ≤ 11 (n = `nums`의 길이)
- 1 ≤ `nums[i]` ≤ 100
- `ops`의 합은 n-1입니다.
- 어떤 순서로 연산자를 넣어도 계산 중간 결과와 최종 결과는 -1,000,000,000 이상 1,000,000,000 이하입니다.

## 함수 시그니처
```cpp
vector<int> solution(vector<int> nums, vector<int> ops)
```

## 입출력 예
| nums | ops | result |
|---|---|---|
| `[3, 4, 5]` | `[1, 0, 1, 0]` | `[35, 17]` |
| `[1, 2, 3, 4, 5, 6]` | `[2, 1, 1, 1]` | `[54, -24]` |
| `[1, 8, 3]` | `[0, 1, 0, 1]` | `[-2, -3]` |

## 입출력 예 설명
**예 #1**
- `3 + 4 × 5` → 앞에서부터 (3 + 4) × 5 = 35
- `3 × 4 + 5` → (3 × 4) + 5 = 17

**예 #2**: 최댓값은 `1 - 2 ÷ 3 + 4 + 5 × 6` = 54, 최솟값은 `1 + 2 + 3 ÷ 4 - 5 × 6` = -24입니다.

**예 #3**
- `1 - 8 ÷ 3` → (1 - 8) ÷ 3 = -7 ÷ 3 = **-2** (0에 가까운 쪽으로 버림)
- `1 ÷ 8 - 3` → 0 - 3 = -3
