# 1번. 배열 회전

## 문제
N × M 크기의 정수 배열 `a`를 **시계 방향으로 90도씩 k번** 회전한 결과를 return 하도록 `solution` 함수를 완성하세요.

N × M 배열을 90도 회전하면 **M × N** 배열이 됩니다.

## 제한사항
- 1 ≤ N, M ≤ 100
- -99 ≤ `a[i][j]` ≤ 99
- 0 ≤ k ≤ 1,000,000,000

## 함수 시그니처
```cpp
vector<vector<int>> solution(vector<vector<int>> a, int k)
```

## 입출력 예
| a | k | result |
|---|---|---|
| `[[1,2,3],[4,5,6]]` | 1 | `[[4,1],[5,2],[6,3]]` |
| `[[1,2,3],[4,5,6]]` | 2 | `[[6,5,4],[3,2,1]]` |
| `[[1,2,3],[4,5,6]]` | 1000000003 | `[[3,6],[2,5],[1,4]]` |

## 입출력 예 설명
**예 #1**
```
1 2 3      시계 방향 90도      4 1
4 5 6     ─────────────→      5 2
                              6 3
```
2 × 3 배열이 3 × 2 배열이 됩니다.

**예 #2**: 두 번 회전하면 180도 회전한 모양입니다.

**예 #3**: 4번 회전하면 원래 모양으로 돌아옵니다.
