# 3번. 보안 구역

## 문제
점검 로봇이 R × C 격자 모양의 공장에서 목적지까지 가야 합니다. 공장에는 잠긴 보안문이 있고, 같은 종류의 출입 카드를 가지고 있어야 문을 통과할 수 있습니다.

| 문자 | 의미 |
|---|---|
| `S` | 출발 위치 (정확히 1개) |
| `E` | 목적지 (정확히 1개) |
| `.` | 빈 칸 |
| `#` | 벽 (지나갈 수 없음) |
| `a`, `b`, `c` | 출입 카드. 그 칸에 들어가면 카드를 줍습니다. |
| `A`, `B`, `C` | 보안문. 대응하는 카드(`A` ↔ `a`, `B` ↔ `b`, `C` ↔ `c`)를 가지고 있어야 들어갈 수 있습니다. |

로봇은 한 번에 상하좌우로 한 칸씩 이동합니다. 한 번 주운 카드는 계속 가지고 있으며, 카드를 써도 사라지지 않습니다. 같은 종류의 카드나 문이 여러 개 있을 수 있습니다.

`S`에서 `E`까지 가는 **최소 이동 횟수**를 return 하도록 `solution` 함수를 완성하세요. 갈 수 없다면 `-1`을 return 하세요.

## 제한사항
- 1 ≤ R, C ≤ 50
- `grid`의 각 문자열 길이는 C이고, 위 문자들로만 이루어져 있습니다.

## 함수 시그니처
```cpp
int solution(vector<string> grid)
```

## 입출력 예
| grid | result |
|---|---|
| `["SaA.E"]` | `4` |
| `["S.A.E", "..###", "b.a.."]` | `10` |
| `["S.B.E", "a####"]` | `-1` |

## 입출력 예 설명
**예 #1**: 오른쪽으로 가면서 카드 `a`를 줍고, 문 `A`를 통과해 4번 만에 도착합니다.

**예 #2**
```
S . A . E
. . # # #
b . a . .
```
문 `A`를 지나려면 먼저 아래로 내려가 카드 `a`를 주워야 합니다. S → (2,2)의 `a`까지 4번, 다시 올라와 문을 지나 E까지 6번. 총 10번입니다.

**예 #3**: 문 `B`를 열 카드 `b`가 없습니다.
