# 4번. 세 팀 나누기

## 문제
엔지니어 n명(0번 ~ n-1번)을 인원이 **같은 세 팀**으로 나누려고 합니다. (n은 3의 배수이며, 한 팀은 n/3명입니다.)

두 엔지니어 i, j가 같은 팀이 되면 **협업 점수** `synergy[i][j]`가 생깁니다. `synergy[i][j]`와 `synergy[j][i]`는 항상 같습니다. 한 팀의 **팀 점수**는 그 팀에 속한 **모든 두 사람 쌍**의 협업 점수를 더한 값입니다.

세 팀의 점수가 최대한 비슷해지도록, **(가장 높은 팀 점수) - (가장 낮은 팀 점수)**의 최솟값을 return 하도록 `solution` 함수를 완성하세요.

## 제한사항
- n은 3, 6, 9, 12 중 하나입니다. (n = `synergy`의 길이)
- 0 ≤ `synergy[i][j]` ≤ 100
- `synergy[i][j]` = `synergy[j][i]`, `synergy[i][i]` = 0

## 함수 시그니처
```cpp
int solution(vector<vector<int>> synergy)
```

## 입출력 예
| synergy | result |
|---|---|
| `[[0,8,4,9,4,5],[8,0,8,1,2,8],[4,8,0,5,7,9],[9,1,5,0,2,5],[4,2,7,2,0,6],[5,8,9,5,6,0]]` | `2` |
| `[[0,1,2],[1,0,3],[2,3,0]]` | `0` |

## 입출력 예 설명
**예 #1**: 6명을 2명씩 세 팀으로 나눕니다. {0, 3}, {1, 5}, {2, 4}로 나누면 팀 점수는 9, 8, 7이고, 차이는 9 - 7 = 2입니다. 이보다 차이가 작게 나누는 방법은 없습니다.

**예 #2**: 한 팀이 1명이라 모든 팀 점수가 0입니다.

## 참고
팀의 이름(번호)은 의미가 없습니다. 예를 들어 {0, 3}, {1, 5}, {2, 4}와 {1, 5}, {0, 3}, {2, 4}는 같은 나누기입니다.
