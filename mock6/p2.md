# 2번. 스택 계산기

## 문제
장비 제어기에는 정수를 담는 **스택** 하나로 동작하는 간단한 계산기가 있습니다. 처음에 스택은 비어 있으며, 명령을 차례대로 실행합니다.

| 명령 | 동작 |
|---|---|
| `"PUSH x"` | 정수 x를 스택 맨 위에 넣습니다. |
| `"POP"` | 맨 위 값을 버립니다. |
| `"DUP"` | 맨 위 값을 복사해서 한 번 더 넣습니다. |
| `"SWAP"` | 맨 위 두 값의 순서를 바꿉니다. |
| `"ADD"` | 맨 위 값 a와 그 아래 값 b를 꺼내고 **b + a**를 넣습니다. |
| `"SUB"` | a와 b를 꺼내고 **b - a**를 넣습니다. |
| `"MUL"` | a와 b를 꺼내고 **b × a**를 넣습니다. |

다음 경우에는 **오류**가 발생하며, 즉시 실행을 멈추고 `"ERROR"`를 return 합니다.
- 명령에 필요한 개수만큼 스택에 값이 없을 때 (`POP`, `DUP`은 1개, 나머지 연산은 2개 필요)
- `ADD`, `SUB`, `MUL`의 결과의 절댓값이 **1,000,000,000을 초과**할 때

오류 없이 모든 명령을 실행했다면, 스택 맨 위의 값을 문자열로 return 합니다. 스택이 비어 있으면 `"EMPTY"`를 return 합니다.

## 제한사항
- 1 ≤ `commands`의 길이 ≤ 1,000
- `PUSH x`의 x는 -1,000,000,000 이상 1,000,000,000 이하의 정수입니다. (음수일 수 있음)
- 명령과 숫자는 공백 하나로 구분됩니다.

## 함수 시그니처
```cpp
string solution(vector<string> commands)
```

## 입출력 예
| commands | result |
|---|---|
| `["PUSH 3", "PUSH 4", "ADD", "DUP", "MUL"]` | `"49"` |
| `["PUSH 2", "PUSH 10", "SUB"]` | `"-8"` |
| `["PUSH 1", "SUB"]` | `"ERROR"` |
| `["PUSH 100000", "DUP", "MUL"]` | `"ERROR"` |
| `["PUSH 5", "POP"]` | `"EMPTY"` |

## 입출력 예 설명
**예 #1**: `[3]` → `[3, 4]` → `[7]` → `[7, 7]` → `[49]`

**예 #2**: a = 10 (맨 위), b = 2이므로 b - a = -8입니다.

**예 #3**: `SUB`에는 값이 2개 필요한데 1개뿐입니다.

**예 #4**: 100000 × 100000 = 10,000,000,000으로 1,000,000,000을 초과합니다.

**예 #5**: 마지막에 스택이 비어 있습니다.

## 참고
`stoi`, `stoll`, `to_string`은 `<string>` 헤더에 포함되어 있어 사용할 수 있습니다.
