# 모의고사 6회 (실전보다 살짝 어려움)

**시험 시간 120분 · 4문제 · C++ · `solution` 함수 작성**

## 규칙
- **문제 틀에 미리 선언된 헤더(`<string>`, `<vector>`)만 사용하세요.** 다른 헤더를 쓰면 `./run.sh`가 ⚠️ 경고를 띄워요.
- 주석과 코딩 스타일도 채점된다는 후기가 있어요.
- 숨은 테스트 케이스가 있어요.

## 문제
| 번호 | 문제 | 유형 | 권장 시간 |
|---|---|---|---|
| 1 | [패턴 검사](p1.md) | 2차원 배열 + 회전 | 20분 |
| 2 | [스택 계산기](p2.md) | 문자열 + 시뮬레이션 | 25분 |
| 3 | [보안 구역](p3.md) | BFS + 상태(열쇠) | 35분 |
| 4 | [세 팀 나누기](p4.md) | 백트래킹 | 40분 |

## 시간 기록
문제를 시작할 때 "p1 시작"처럼 말해주시면 기록해 드려요.

## 채점 / 디버깅
```bash
./run.sh mock6/p1          # 전체 테스트 채점
./debug.sh mock6/p1 3      # 3번 테스트 하나만 실행 (cout 출력 전부 보임)
```

## 제출 전 점검
- [ ] 예제 하나를 손으로 따라가서 문제를 맞게 이해했는지 확인했나?
- [ ] 이상(≥) / 초과(>) / 이하(≤) / 미만(<)을 맞게 썼나?
- [ ] 빈 상태(빈 스택, 빈 배열)에서 꺼내기 전에 크기를 확인했나?
- [ ] BFS: 위치 외의 조건(열쇠 등)을 방문 배열에 넣었나?
- [ ] 백트래킹: 바꾼 값을 재귀 호출 뒤에 되돌렸나? 고르기면 `start`부터 했나?
- [ ] 결과가 int 범위를 넘을 수 있으면 `long long`을 썼나?
- [ ] 디버깅용 `<iostream>`, `cout`을 지웠나?
