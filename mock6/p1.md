# 1번. 패턴 검사

## 문제
웨이퍼 표면을 N × N 격자로 촬영한 이미지 `grid`와, 찾아야 할 M × M 크기의 결함 패턴 `pattern`이 주어집니다. 각 칸은 `#`(결함) 또는 `.`(정상)입니다.

결함 패턴은 웨이퍼 위에서 **회전된 상태**로 나타날 수 있습니다. 패턴을 시계 방향으로 0도, 90도, 180도, 270도 회전한 네 가지 모양 중 **하나라도** grid의 M × M 부분과 **모든 칸이 똑같으면**, 그 위치에서 패턴이 발견된 것입니다. (뒤집기는 고려하지 않습니다.)

패턴이 발견되는 **위치(부분 격자의 왼쪽 위 칸)의 개수**를 return 하도록 `solution` 함수를 완성하세요. 한 위치에서 여러 회전 모양이 일치해도 **한 번만** 셉니다.

## 제한사항
- 1 ≤ M ≤ N ≤ 50
- M ≤ 10
- `grid`, `pattern`은 `#`과 `.`로만 이루어져 있습니다.

## 함수 시그니처
```cpp
int solution(vector<string> grid, vector<string> pattern)
```

## 입출력 예
| grid | pattern | result |
|---|---|---|
| `["##..", "#...", "...#", "..##"]` | `["##", "#."]` | `2` |
| `["#..", "##.", "..."]` | `["##", "#."]` | `1` |
| `["...", "...", "..."]` | `["..", ".."]` | `4` |

## 입출력 예 설명
패턴 `["##", "#."]`의 네 가지 회전 모양은 다음과 같습니다.
```
  0도     90도    180도   270도
  ##      ##      .#      #.
  #.      .#      ##      ##
```

**예 #1**: 왼쪽 위 (0,0)에서 0도 모양이, (2,2)에서 180도 모양이 일치합니다. 2곳입니다.

**예 #2**: (0,0)의 부분 격자 `["#.", "##"]`가 270도 모양과 일치합니다. 1곳입니다.

**예 #3**: 2 × 2 부분 격자를 놓을 수 있는 위치 4곳이 모두 일치합니다. 네 회전 모양이 모두 같지만 위치마다 한 번만 셉니다.
