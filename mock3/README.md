## 규칙 (2회와 동일)
- **문제 틀에 미리 선언된 헤더(`<string>`, `<vector>`)만 사용하세요.** `<algorithm>`, `<queue>`, `<map>`, `<sstream>` 등은 쓰지 않아요. 다른 헤더를 쓰면 `./run.sh`가 ⚠️ 경고를 띄워요.
- 주석과 코딩 스타일도 채점된다는 후기가 있어요.
- 숨은 테스트 케이스가 있어요.
