# 2번. 로트 순위

## 문제
웨이퍼 로트(lot)마다 품질 검사를 여러 번 할 수 있습니다. 검사 기록은 `"로트ID 점수"` 형식의 문자열로 주어집니다.

각 로트의 순위는 다음 기준으로 정합니다.
1. 그 로트의 **최고 점수**가 높을수록 앞
2. 최고 점수가 같으면 **검사 횟수가 적을수록** 앞
3. 그것도 같으면 로트ID의 **사전순**으로 앞

순위가 높은 로트부터 **최대 k개**의 로트ID를 담은 배열을 return 하도록 `solution` 함수를 완성하세요. 로트가 k개보다 적으면 모든 로트를 순위대로 return 합니다.

## 제한사항
- 1 ≤ `logs`의 길이 ≤ 1,000
- 로트ID는 알파벳 대문자와 숫자로 이루어진 길이 1 이상 10 이하의 문자열입니다.
- 0 ≤ 점수 ≤ 100 (정수)
- 1 ≤ k ≤ 1,000
- **이번 세트 규칙상 `sort`(`<algorithm>`)를 쓸 수 없습니다.** 정렬이 필요하면 직접 구현하세요.

## 함수 시그니처
```cpp
vector<string> solution(vector<string> logs, int k)
```

## 입출력 예
| logs | k | result |
|---|---|---|
| `["L1 80", "L2 95", "L1 95", "L4 95", "L3 70", "L2 60"]` | 3 | `["L4", "L1", "L2"]` |
| `["B 50", "A 50"]` | 5 | `["A", "B"]` |

## 입출력 예 설명
**예 #1**

| 로트 | 최고 점수 | 검사 횟수 |
|---|---|---|
| L1 | 95 | 2 |
| L2 | 95 | 2 |
| L3 | 70 | 1 |
| L4 | 95 | 1 |

최고 점수 95인 로트 중 L4는 검사 횟수가 1번이라 가장 앞입니다. L1과 L2는 점수와 횟수가 같으므로 사전순입니다. 상위 3개는 L4, L1, L2입니다.

**예 #2**: 로트가 2개뿐이므로 둘 다 return 합니다. 점수와 횟수가 같으므로 사전순입니다.
