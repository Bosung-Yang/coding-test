# 3번. 연쇄 제거

## 문제
R × C 크기의 적재함에 부품 블록이 쌓여 있습니다. 각 칸은 빈 칸 `.` 또는 부품 종류를 나타내는 알파벳 대문자 `A` ~ `E` 중 하나입니다. 처음 상태에서 모든 블록은 아래로 떨어져 정착해 있습니다. (블록 아래에 빈 칸이 없음)

다음 과정을 **제거할 블록이 없을 때까지** 반복합니다. 이 과정 한 번을 **1라운드**라고 합니다.

1. **같은 종류**의 블록이 상하좌우로 연결된 덩어리 중, 크기가 **k개 이상**인 덩어리를 모두 찾습니다.
2. 찾은 덩어리들을 **동시에** 모두 제거합니다.
3. 남은 블록들이 **아래로 떨어집니다.** 각 열에서 블록들은 순서를 유지한 채, 바로 아래가 빈 칸이 아닐 때까지 내려갑니다.

블록이 떨어진 뒤 새로운 덩어리가 생기면 다음 라운드에서 다시 제거됩니다.

진행된 **라운드 수**와 **제거된 블록의 총 개수**를 `[라운드 수, 제거된 블록 수]` 형태로 return 하도록 `solution` 함수를 완성하세요.

## 제한사항
- 1 ≤ R, C ≤ 30
- 2 ≤ k ≤ 10
- `grid`의 각 문자열 길이는 C이고, `.`, `A` ~ `E`로만 이루어져 있습니다.
- 처음 상태에서 모든 블록은 정착해 있습니다.

## 함수 시그니처
```cpp
vector<int> solution(vector<string> grid, int k)
```

## 입출력 예
| grid | k | result |
|---|---|---|
| `["......", "..B...", "A.BB..", "AABCC."]` | 3 | `[1, 7]` |
| `["A..", "B..", "B..", "BAA"]` | 3 | `[2, 6]` |

## 입출력 예 설명
**예 #1**
```
......        ......        ......
..B...        ......        ......
A.BB..   →    ......   →    ......
AABCC.        ...CC.        ...CC.
```
A 덩어리(3개)와 B 덩어리(4개)를 동시에 제거합니다. 남은 C 덩어리는 2개뿐이라 끝납니다. 1라운드, 7개 제거.

**예 #2**
```
A..      A..      ...      ...      ...
B..      ...      ...      ...      ...
B..  →   ...  →   ...  →   ...  →   ...
BAA      .AA      AAA      AAA      ...
     제거(B 3개)  낙하    제거(A 3개)
```
1라운드에 B 3개가 제거되고, A가 떨어져 A 3개가 연결됩니다. 2라운드에 A 3개가 제거됩니다. 2라운드, 6개 제거.
