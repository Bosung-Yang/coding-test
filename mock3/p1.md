# 1번. 순찰 로봇

## 문제
순찰 로봇이 R × C 격자 모양의 공장 안을 움직입니다. 각 칸은 빈 칸 `.`, 벽 `#`, 로봇의 시작 위치 `S`(정확히 1개, 빈 칸으로 취급) 중 하나입니다. 로봇은 처음에 **위쪽(북쪽)**을 바라보고 있습니다.

로봇은 명령을 차례대로 수행합니다.

| 명령 | 동작 |
|---|---|
| `"L"` | 제자리에서 왼쪽으로 90도 회전합니다. |
| `"R"` | 제자리에서 오른쪽으로 90도 회전합니다. |
| `"F k"` | 바라보는 방향으로 **한 칸씩** k번 전진합니다. 다음 칸이 벽이거나 격자 밖이면 그 자리에 멈추고, **이 명령의 남은 전진은 취소됩니다.** |

모든 명령을 수행한 뒤 로봇의 위치 (행, 열)과, 로봇이 **한 번이라도 지나간 서로 다른 칸의 수**(시작 칸 포함)를 `[행, 열, 칸 수]` 형태로 return 하도록 `solution` 함수를 완성하세요.

## 제한사항
- 1 ≤ R, C ≤ 50
- 1 ≤ `commands`의 길이 ≤ 100
- `"F k"`에서 1 ≤ k ≤ 100
- 맨 위 행이 0행, 맨 왼쪽 열이 0열입니다.

## 함수 시그니처
```cpp
vector<int> solution(vector<string> grid, vector<string> commands)
```

## 입출력 예
| grid | commands | result |
|---|---|---|
| `["....", ".#..", "S..."]` | `["F 5", "R", "F 2", "R", "F 1"]` | `[1, 2, 6]` |
| `["...", "S..", "..."]` | `["L", "L", "F 1", "F 1", "R", "R", "F 2"]` | `[0, 0, 3]` |

## 입출력 예 설명
**예 #1**
- `F 5`: (2,0)에서 위로 (1,0), (0,0)까지 간 뒤, 다음 칸이 격자 밖이라 멈춥니다.
- `R`: 오른쪽(동쪽)을 봅니다. `F 2`: (0,1), (0,2)
- `R`: 아래(남쪽)를 봅니다. `F 1`: (1,2)
- 지나간 칸은 (2,0), (1,0), (0,0), (0,1), (0,2), (1,2)로 6개입니다.

**예 #2**
- `L`, `L`: 아래쪽을 봅니다. `F 1`: (2,0). `F 1`: 격자 밖이라 이동하지 않습니다.
- `R`, `R`: 위쪽을 봅니다. `F 2`: (1,0), (0,0)
- (1,0)은 두 번 지나갔지만 한 번만 셉니다. 서로 다른 칸은 (1,0), (2,0), (0,0)으로 3개입니다.
