# 4번. 검사 경로

## 문제
점검 로봇이 R × C 격자 모양의 공장에서 모든 검사 지점을 방문해야 합니다. 각 칸은 다음 중 하나입니다.

| 문자 | 의미 |
|---|---|
| `S` | 로봇의 출발 위치 (정확히 1개) |
| `P` | 검사 지점 (1개 이상 8개 이하) |
| `.` | 빈 칸 |
| `#` | 벽 (지나갈 수 없음) |

로봇은 한 번에 상하좌우로 한 칸씩 이동합니다. 검사 지점은 그 칸에 도착하면 방문한 것으로 칩니다. **방문 순서는 자유**이며, 이미 방문한 검사 지점이나 출발 위치도 지나갈 수 있습니다.

로봇이 `S`에서 출발해 **모든 검사 지점을 방문한 뒤 다시 `S`로 돌아오는** 최소 이동 횟수를 return 하도록 `solution` 함수를 완성하세요. 불가능하다면 `-1`을 return 하세요.

## 제한사항
- 1 ≤ R, C ≤ 50
- `P`의 개수는 1개 이상 8개 이하입니다.
- `grid`의 각 문자열 길이는 C이고, 위 네 문자로만 이루어져 있습니다.

## 함수 시그니처
```cpp
int solution(vector<string> grid)
```

## 입출력 예
| grid | result |
|---|---|
| `["S.P", "...", "P.."]` | `8` |
| `["S#P", "##.", "P.."]` | `-1` |
| `["S....", "###.#", "P...P"]` | `18` |

## 입출력 예 설명
**예 #1**: S → (0,2) 2번, (0,2) → (2,0) 4번, (2,0) → S 2번. 총 8번입니다.

**예 #2**: S가 벽에 둘러싸여 있어 어디로도 갈 수 없습니다.

**예 #3**: S → (2,4) 6번, (2,4) → (2,0) 4번, (2,0) → S 8번. 총 18번입니다.
