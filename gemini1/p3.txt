문제 설명
패키징 봇이 여러 개의 반도체 패키징 작업을 수행해야 합니다. 작업 정보는 [작업 번호, 요청 시간, 소요 시간] 형태의 2차원 배열 jobs로 주어집니다.
봇은 한 번에 하나의 작업만 수행할 수 있으며, 규칙은 다음과 같습니다.

현재 실행 가능한(요청 시간이 지난) 작업 중 소요 시간이 가장 짧은 작업을 먼저 수행합니다.

소요 시간이 같은 작업이 여러 개라면, 요청 시간이 빠른 작업을 먼저 수행합니다.

소요 시간과 요청 시간마저 같다면, 작업 번호가 작은 것을 먼저 수행합니다.

현재 봇이 쉬고 있고 대기 중인 작업이 없다면, 가장 먼저 요청되는 작업을 수행합니다.

모든 작업을 처리했을 때, 작업이 완료되는 순서대로 작업 번호를 배열에 담아 return 하도록 solution 함수를 완성해주세요.

제한사항

jobs의 길이는 1 이상 10,000 이하입니다.

jobs의 각 원소는 [id, request_time, process_time] 입니다.

id는 1 이상 10,000 이하의 정수이며 중복되지 않습니다.

request_time은 0 이상 100,000 이하입니다.

process_time은 1 이상 1,000 이하입니다.
