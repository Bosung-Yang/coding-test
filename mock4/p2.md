# 2번. 장비 코드 검증

## 문제
공장의 모든 장비에는 코드가 붙어 있습니다. 올바른 장비 코드는 다음 조건을 **모두** 만족합니다.

1. 길이가 정확히 **9**입니다.
2. 형식은 `XX-NNNN-C`입니다.
   - 0, 1번째 문자 `XX`: 알파벳 **대문자** (`A` ~ `Z`)
   - 2번째, 7번째 문자: `-`
   - 3 ~ 6번째 문자 `NNNN`: 숫자 (`0` ~ `9`)
3. 8번째 문자 `C`는 **검증 문자**로, `NNNN`의 네 숫자를 더한 값을 26으로 나눈 나머지를 r이라고 할 때 `'A' + r`이어야 합니다. (나머지가 0이면 `A`, 1이면 `B`, …, 25이면 `Z`)

장비 코드 목록 `codes`가 주어질 때, **올바르지 않은 코드의 인덱스**를 오름차순으로 담은 배열을 return 하도록 `solution` 함수를 완성하세요. 모든 코드가 올바르면 `[-1]`을 return 하세요.

## 제한사항
- 1 ≤ `codes`의 길이 ≤ 1,000
- 각 코드의 길이는 1 이상 20 이하이며, 공백 없이 출력 가능한 ASCII 문자로 이루어져 있습니다.
- 인덱스는 0부터 시작합니다.

## 함수 시그니처
```cpp
vector<int> solution(vector<string> codes)
```

## 입출력 예
| codes | result |
|---|---|
| `["AB-1234-K", "ab-1234-K", "XY-0000-A", "XY-000-AA", "CD-9999-K"]` | `[1, 3]` |
| `["ZZ-0001-B"]` | `[-1]` |

## 입출력 예 설명
**예 #1**
| 인덱스 | 코드 | 판정 |
|---|---|---|
| 0 | `AB-1234-K` | 1+2+3+4 = 10, 10 % 26 = 10 → `K` ✅ |
| 1 | `ab-1234-K` | 앞 두 글자가 소문자 ❌ |
| 2 | `XY-0000-A` | 합 0 → `A` ✅ |
| 3 | `XY-000-AA` | 6번째 문자가 숫자가 아니라 `-` ❌ |
| 4 | `CD-9999-K` | 합 36, 36 % 26 = 10 → `K` ✅ |

**예 #2**: 합 1 → `B`이므로 올바른 코드입니다.
