# 3번. 결함 영역

## 문제
웨이퍼 검사 장비가 웨이퍼 표면을 R × C 격자로 나누어 촬영했습니다. 각 칸은 정상 `.` 또는 결함 `#`입니다.

결함 칸이 **8방향**(상하좌우 + 대각선 4방향)으로 이어져 있으면 같은 **결함 영역**에 속합니다.

결함 영역의 **개수**와 **가장 큰 결함 영역의 칸 수**를 `[개수, 최대 칸 수]` 형태로 return 하도록 `solution` 함수를 완성하세요. 결함이 없으면 `[0, 0]`을 return 하세요.

## 제한사항
- 1 ≤ R, C ≤ 100
- `grid`의 각 문자열 길이는 C이고, `.`와 `#`로만 이루어져 있습니다.

## 함수 시그니처
```cpp
vector<int> solution(vector<string> grid)
```

## 입출력 예
| grid | result |
|---|---|
| `["#..#", ".#..", "...#", "##.#"]` | `[4, 2]` |
| `["...", "..."]` | `[0, 0]` |
| `["#"]` | `[1, 1]` |

## 입출력 예 설명
**예 #1**
```
# . . #      영역 1 : (0,0), (1,1)   ← 대각선으로 연결
. # . .      영역 2 : (0,3)
. . . #      영역 3 : (2,3), (3,3)
# # . #      영역 4 : (3,0), (3,1)
```
결함 영역은 4개이고, 가장 큰 영역은 2칸입니다.
