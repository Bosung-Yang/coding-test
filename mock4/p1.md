# 1번. 센서 경보 구간

## 문제
공정 장비의 온도 센서가 1분마다 측정한 값이 배열 `readings`로 주어집니다. 측정값이 기준값 `t`를 **초과**하면(`값 > t`, 같은 값은 해당 없음) **경보**가 울립니다.

경보가 **연속으로** 울린 구간을 하나의 **경보 구간**이라고 할 때, 경보 구간의 **개수**와 **가장 긴 경보 구간의 길이**를 `[개수, 최대 길이]` 형태로 return 하도록 `solution` 함수를 완성하세요. 경보 구간이 없으면 `[0, 0]`을 return 하세요.

## 제한사항
- 1 ≤ `readings`의 길이 ≤ 1,000
- 0 ≤ `readings[i]` ≤ 1,000
- 0 ≤ `t` ≤ 1,000

## 함수 시그니처
```cpp
vector<int> solution(vector<int> readings, int t)
```

## 입출력 예
| readings | t | result |
|---|---|---|
| `[3, 7, 8, 2, 9, 9, 9, 1]` | 5 | `[2, 3]` |
| `[1, 2, 3]` | 5 | `[0, 0]` |
| `[6, 6]` | 5 | `[1, 2]` |

## 입출력 예 설명
**예 #1**: 5보다 큰 값의 연속 구간은 `[7, 8]`과 `[9, 9, 9]` 두 개입니다. 가장 긴 구간의 길이는 3입니다.

**예 #2**: 5보다 큰 값이 없습니다.

**예 #3**: 배열 전체가 하나의 경보 구간입니다.
