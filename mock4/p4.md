# 4번. 장비 선택

## 문제
새 공정 라인에 전력 공급 장비를 설치하려고 합니다. 후보 장비는 n대(0번 ~ n-1번)이고, i번 장비의 설치 비용은 `cost[i]`, 공급 전력은 `power[i]`입니다. 각 장비는 최대 한 번만 설치할 수 있습니다.

설치한 장비들의 공급 전력 합이 **`needPower` 이상**이 되어야 합니다. 단, 일부 장비는 서로 간섭하므로 **함께 설치할 수 없습니다.** `conflicts`의 각 원소 `[a, b]`는 a번 장비와 b번 장비를 함께 설치할 수 없다는 뜻입니다.

조건을 만족하는 **최소 설치 비용**을 return 하도록 `solution` 함수를 완성하세요. 조건을 만족할 수 없다면 `-1`을 return 하세요.

## 제한사항
- 1 ≤ n ≤ 15 (n = `cost`의 길이 = `power`의 길이)
- 1 ≤ `cost[i]`, `power[i]` ≤ 100
- 1 ≤ `needPower` ≤ 1,500
- 0 ≤ `conflicts`의 길이 ≤ 105
- `conflicts`의 각 원소 `[a, b]`는 0 ≤ a, b < n, a ≠ b이며, 같은 쌍이 중복되지 않습니다.

## 함수 시그니처
```cpp
int solution(vector<int> cost, vector<int> power, int needPower, vector<vector<int>> conflicts)
```

## 입출력 예
| cost | power | needPower | conflicts | result |
|---|---|---|---|---|
| `[5, 3, 4, 6]` | `[4, 2, 3, 5]` | 7 | `[]` | `9` |
| `[5, 3, 4, 6]` | `[4, 2, 3, 5]` | 7 | `[[0, 2], [1, 3]]` | `10` |
| `[5, 3, 4, 6]` | `[4, 2, 3, 5]` | 100 | `[]` | `-1` |

## 입출력 예 설명
**예 #1**: 0번 + 2번 장비(전력 4+3=7, 비용 5+4=9) 또는 1번 + 3번 장비(전력 2+5=7, 비용 3+6=9)가 최소입니다.

**예 #2**: 위 두 조합이 모두 간섭으로 불가능합니다. 2번 + 3번 장비(전력 3+5=8, 비용 4+6=10)가 최소입니다.

**예 #3**: 모든 장비의 전력을 더해도 14라서 100을 만들 수 없습니다.
